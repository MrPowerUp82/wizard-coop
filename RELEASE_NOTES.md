# Arcana Survivors 0.2.0 — versão web

- Nova arte de abertura no menu e banner do projeto no README.
- Tela de créditos com Guilherme de Lucca Moraes e Luis Paula Alves em ideias e sugestões.
- Jogo web cooperativo com os seis reinos, Códex, Grimório, desafios e suporte offline.
- Personagens desbloqueáveis O Desenvolvedor, Guardião da Aurora e The God, com sprites e habilidades próprios.
- Multiplayer web com salas, reconexão e compatibilidade com o port nativo para PC.

A versão web é publicada pelo GitHub Pages. Os pacotes atuais de Switch, PS Vita, PSP, Windows e Linux estão na [release v0.9.3 do port nativo](https://github.com/MrPowerUp82/wizard-coop-ports/releases/tag/v0.9.3).
